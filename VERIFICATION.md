# Проверка OrgLens

Дата: 23 сентября 2026. Проверено на macOS, Node.js 24.21.0.

- ESLint: без ошибок и предупреждений.
- TypeScript: без ошибок.
- Автотесты: 9 из 9 пройдены.
- Production-сборка Next.js: успешно.
- HTTP smoke: реальные загрузки двух PDF, 17 запросов к локальному тестовому провайдеру, поток прогресса, отчёт и ошибки загрузки — успешно.
- Демопример: 12 наблюдений, 27 цитат; все цитаты присутствуют на указанных страницах исходных PDF.
- Браузер: запуск демо, вкладки, раскрытие доказательств, переход из заключения к наблюдению — проверены.
- Адаптивность: при ширине 1366 и 390 px ширина документа равна ширине viewport, горизонтального переполнения нет.
- Git: .env.local, node_modules и .next игнорируются; коммиты и внешняя публикация не выполнялись.

Ограничения проверки: реальный NVIDIA API не вызван, поскольку ключ не предоставлен. Тестовый провайдер подтверждает работоспособность конвейера, но не качество семантических выводов выбранной модели. Запуск на Windows не выполнялся. DOCX поддержан базово; основная проверка выполнена на двух приложенных PDF.
