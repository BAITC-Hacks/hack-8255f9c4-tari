# Публикация OrgLens

Проект подготовлен для одного постоянно работающего Node.js-сервера на Render.
Регистрация и выбор тарифа выполняются владельцем проекта. Платный тариф не создавался.

1. Зарегистрируйтесь на https://dashboard.render.com/ через свой GitHub.
2. Загрузите изменения проекта в общий репозиторий и объедините их в main.
3. В Render выберите New → Web Service и подключите репозиторий BAITC-Hacks/hack-8255f9c4-tari. Если он не виден, владелец организации должен разрешить Render доступ к этому репозиторию.
4. Runtime: Node. Build Command: `npm ci --include=dev && npm run build`. Start Command: `npm run start:hosted`. Health Check: `/api/config`.
5. Добавьте NODE_VERSION=24 и DEMO_MODE=true. Выберите подходящий тариф и запустите размещение. После успешного запуска Render покажет публичную ссылку.
6. Сначала проверьте демопример, три языка, мобильный экран и скачивание PDF по этой ссылке.

Файл render.yaml содержит те же настройки для варианта New → Blueprint. Тариф и цену проверьте перед подтверждением: файл не задаёт бесплатный тариф.

## Включение своего AI

В Environment хостинга добавьте AI_API_KEY, AI_BASE_URL и AI_MODEL из своей локальной настройки. Не вставляйте ключ в GitHub, чат или клиентский код. Переключите DEMO_MODE=false.

Задайте APP_ACCESS_CODE случайной строкой минимум 16 символов. Передайте этот код только команде/жюри: он открывает платные анализ и помощника. API-ключ для входа не используется. При запуске production без достаточно длинного кода платные запросы блокируются. Код вводится на странице и хранится только в памяти открытой вкладки.

По умолчанию один сервер допускает 3 запуска анализа и 30 запросов помощнику за час. ANALYSIS_HOURLY_LIMIT и ASSISTANT_HOURLY_LIMIT изменяют эти значения. Лимиты общие для всех пользователей этого процесса, считаются с первого запроса и сбрасываются при перезапуске. Это защита демонстрации, а не гарантия финансового потолка. Не запускайте несколько экземпляров с платным AI без общего внешнего ограничителя. Установите контроль расходов также у провайдера.

Анализ может занимать несколько минут. Протестируйте полный цикл на выбранном тарифе; время запуска, память и проксирование долгих соединений зависят от хостинга. Для Vercel нужна отдельная адаптация больших загрузок: лимит тела запроса функции 4.5 МБ меньше текущих 20 МБ приложения.

## Отчёты и файлы

- PDF создаётся в браузере; отчёт не отправляется в отдельный сервис экспорта.
- Сохранение последних пяти отчётов включается пользователем. IndexedDB содержит текст отчёта и цитаты. Исходные PDF/DOCX туда не записываются. Удаление доступно рядом с каждым сохранённым отчётом.
- Повторный анализ сравнивает SHA-256 обоих файлов с учётом порядка, версии конвейера и модели. Новую проверку можно принудительно запустить флажком.
- Исходные страницы выбранных PDF открываются из локальных blob-ссылок. В сохранённом отчёте без повторного выбора файлов этих ссылок нет.
- При отмене прекращаются последующие запросы к AI. Уже выполненная работа провайдера может быть оплачена.
